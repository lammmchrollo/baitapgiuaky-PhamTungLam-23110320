Họ và tên: Phạm Tùng Lâm
MSSV: 23110320

## Danh sach bai tap

1. `todo_list.py`
- To-do List don gian: them cong viec, hien thi danh sach, luu vao `todo_list.txt`.

2. `phan_tich_van_ban.py`
- Tach tu tu doan van, dem tong so tu, tim tu xuat hien nhieu nhat.

3. `tinh_bmi.py`
- Tinh chi so BMI, phan loai (gay / binh thuong / thua can), dua ra loi khuyen.

4. `mini_hangman.py`
- Tro choi doan chu cai (Hangman mini).
- Luu ket qua moi van vao `ket_qua_hangman.txt`.

5. `quan_ly_kho.py`
- Quan ly ton kho co ban (them mat hang, cap nhat so luong).
- Ve bieu do tron va luu thanh `bieu_do_kho_hang.png`.

## Yeu cau

- Python 3.8+
- Thu vien can them cho bai `quan_ly_kho.py`:

```bash
pip install matplotlib
```

## Cach chay

Mo terminal tai thu muc du an, sau do chay mot trong cac lenh:

```bash
python todo_list.py
python phan_tich_van_ban.py
python tinh_bmi.py
python mini_hangman.py
python quan_ly_kho.py
```

## Tep du lieu/ket qua

- `todo_list.txt`: Danh sach cong viec da luu
- `ket_qua_hangman.txt`: Lich su ket qua cac van choi Hangman
- `bieu_do_kho_hang.png`: Bieu do ton kho duoc xuat tu bai quan ly kho
